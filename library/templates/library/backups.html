Backups in that folder

When a new backup succeeds, the oldest ones beyond the limit are deleted. Only files named homeflix-YYYYMMDD-HHMMSS.tar.gz are ever touched.

How do I restore a backup?
  1. Stop HomeFlix (sudo systemctl stop homeflix).
  2. Unpack the archive somewhere: mkdir /tmp/hf-restore && tar -xzf homeflix-….tar.gz -C /tmp/hf-restore.
  3. Copy db.sqlite3, thumbnails/ and subtitles/ from there back into the HomeFlix folder (replacing the current ones).
  4. Start it again (sudo systemctl start homeflix).

Not included on purpose: homeflix.env (your secret key) and the saved YouTube cookies, since a backup folder is often on a shared drive.
