Folders

Type the full path as the server sees it (for example /mnt/big/YouTube). The network path is optional: it is what the player shows under a video so you can open the file from another PC (for example \\192.168.1.39\big\YouTube).

What happens when I change this?
  • Adding a folder: press Save, then Rescan (it also happens automatically every 30 minutes). A big folder takes a while, because every new video gets a thumbnail.
  • Removing a folder only removes it from HomeFlix, no file is touched. Its videos disappear from the library, but their history, notes and playlist entries are kept and come back if you add the folder again.
  • Changing the path of a folder (say the drive got a new mount point) counts as removing the old one and adding a new one, so those videos start over without history. If you can, keep the path and change what is mounted there instead.
  • A folder that is offline (drive unplugged, share not mounted) is skipped, and its videos are not marked missing.
  • Switching the main folder doesn't make earlier downloads look new: "already downloaded" checks every folder.
  • Organize by date keeps each video in the folder it is already in.
